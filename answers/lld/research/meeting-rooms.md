## Notes
- The page's core API uses the method names of the real prompts: `scheduleMeeting` (Uber), `bookRoom`, `getAvailableRooms`,
  `cancelBooking`, `listBookingsForRoom`, `listBookingsForEmployee` (Salesforce, codezym Q44), `bookMeeting` / `cancelMeeting`
  (codezym Q29, in FU 1).
- Interval convention: the page uses half-open [start, end) (Udaan's "back-to-back allowed", Cleartrip's hour slots). The codezym
  variants tagged Uber / Salesforce / Amazon use closed intervals; FU 1 shows the one-line conversion, and test 14 asserts
  codezym's own examples.
- Ranked for his targets (Indian product companies, FAANG and GCCs in India): Uber, Flipkart, Cleartrip, PhonePe, Zepto, Meesho,
  Udaan, Amazon, Adobe, Microsoft, Atlassian, ThoughtSpot, Salesforce. No AI-lab-only variant exists for this system.
- Not added, with the reason: PhonePe's "shifts per user" (the slot finder would treat hours outside a shift as busy blocks;
  one report, 2023); Udaan's daily limit K (the tier quota in FU 11 is the same per-member counter); Flipkart's "trending
  doctor" bonus; LeetCode 731 (no triple booking), for which no report in this evidence set asks.
- Search limits: the WebSearch budget was already used up (200 of 200). Every row above was read first-hand; codezym renders on
  the client, so its statements were read from its JSON API.

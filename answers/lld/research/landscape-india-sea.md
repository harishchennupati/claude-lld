# LLD / machine-coding landscape — Indian product companies + Singapore / South-East Asia (2023-2026)

Compiled 2026-09-26. Companion data file: `landscape-india-sea.json` (same entries, machine-readable).

## 0. How this was built, and how much to trust it

**Sources actually read**

| Source | What was done | Strength |
|---|---|---|
| LeetCode Discuss (public GraphQL) | 85 company names x 3-5 keyword searches ("{company} machine coding", "{company} LLD", "{company} low level design", + "interview experience"/"singapore" for SEA) and 88 topic searches ("{topic} machine coding"/"{topic} LLD"). Kept posts created 2023-01-01 to 2026-09-26 whose **title names the company**: 1,326 posts fetched in full; the LLD parts of each were extracted and read. | **First-hand** when the author says they sat the round (company + date in post). Main evidence. |
| codezym.com company pages (read through its JSON API) | 433 questions with company tags; per-company format notes. | **Aggregator** — the site owner tags questions; not dated, not first-hand. Used only as a hint or tie-breaker. |
| workat.tech practice list | 10 problems (Parking Lot, Splitwise, Chess, Snake & Ladder, 2048, Tic-tac-toe, Library, Trello, KV store, Kafka queue). | Aggregator. |
| Web search snippets (Medium, Glassdoor, NodeFlair, GFG, company pages) | Most of these sites return HTTP 403 to scripts, so only the search-engine summary was seen. Wise's official interview page was read in full. | **Snippet-only** = weak; labelled wherever used. |

**Rules used**
- "Reports" = number of distinct first-hand posts (two posts by the same author about the same round count once; compiled "asked in X" posts count zero).
- Year = interview year when the post states it, otherwise the post year.
- Tier 1 = asked at 4+ companies (first-hand); tier 2 = 2-3 companies; tier 3 = one company's signature question.
- Evidence links are LeetCode post ids (`https://leetcode.com/discuss/post/<id>/`).

**Known blind spots.** LeetCode is heavily Indian, so SEA companies are under-sampled. Glassdoor, Blind, Reddit, 1point3acres and NodeFlair could not be read (bot walls), and the web-search budget ran out before the last two SEA queries. For SEA, "no evidence found" means *not found in LeetCode posts + search snippets*, not "never asked".

## 1. Headline

1. **Tier-1 new problems** (asked at 4+ companies, none in the current 34 pages): train/flight seat booking (8 reports), job/task scheduler (7), inventory + order management with stock blocking (7), library management (6), social feed + comments (6), leaderboard service (6), shopping cart / checkout (5), meeting/conference-room booking (5), stock broker + portfolio app (5), URL shortener as LLD (5), Jira/Trello-style task tracker (4).
2. **Most repeated overall is still an existing page**: Splitwise (12 reports across 10 companies, one of them as an HLD round), then parking lot (10), rate limiter (8), pub-sub (7), ride sharing (7), in-memory DB / KV (7).
3. **Company signatures worth knowing by name**: Flipkart (BNPL, auction "highest unique bid", bug bounty, P2P delivery, FoodKart), PhonePe (hackathon platform, app-version rollout, user-journey DAG, payment-gateway router), Razorpay (in-memory search engine, pub-sub with offsets, git-like VCS, load balancer), Meesho (inventory block/confirm), CRED (microprocessor/registers), Atlassian (middleware router, snake game, subscription cost, rate limiter), Uber (employee directory, train-platform, file system with `cd *`), Rippling (delivery-cost tracker, music analytics, expense rules engine, access manager), Juspay (Tree of Space, thread-safe), Wise (circuit breaker), Gojek (extend a parking-lot codebase; BitDB), Agoda (code-review "platform" round).
4. **Format shifts 2025-2026**: AI tools are now *allowed and judged* in some rounds (Razorpay 2025-26, CRED 2025, Microsoft "LLD with LLM access" 2026, Rippling AI-coding 2026, LinkedIn staff 2026, Tekion "laptop with AI" 2026) while Flipkart's June-2026 drive **prohibits** AI. Zepto, Cars24 and Tekion outsource LLD/DSA rounds to InterviewVector/BarRaiser, where the score is class + DB schema + API design rather than runnable code.
5. **SEA reality**: the Indian-style 90-minute runnable machine-coding round shows up almost only where a company interviews in India (Gojek/GoTo Bangalore, Agoda Gurugram, Uber/Atlassian/Rippling Bangalore). Singapore loops at Grab, Shopee, TikTok/ByteDance are DSA + HLD. The SEA-flavoured equivalents are **Wise pair programming**, **Stripe integration/bug-bash**, **Coinbase level-by-level CodeSignal**, and **Agoda code review**.
